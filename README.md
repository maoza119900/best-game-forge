Lanternkeep: a tower-defence game on a night island. Shadow moths march a winding path to the Heart Lantern; build lantern towers on stone pads, spend embers, upgrade towers, and hold the light through all 8 waves.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network: the game is plain static files under game/.

## How to play

- Click a stone pad to build the selected lantern tower (Ember, Frost, Gale).
- Keys 1/2/3 pick a lantern type. Space starts the next wave.
- Click a built tower to select it, then U upgrades it and X sells it.
- P pauses, M mutes, R restarts. Survive all 8 waves to win; if the Heart Lantern's HP reaches 0, the light fades.
